# 📊 Food Delivery Performance Dashboard

## 🏆 Project Background
This project was completed as part of the **April Data Visualization Challenge** organized by the Power BI Project Club.

The challenge focused on analyzing food delivery operations across customers, drivers, and restaurants to uncover patterns and deliver actionable insights using Power BI.

---

## 🎯 Objective
To analyze delivery performance data and identify inefficiencies across the order lifecycle — from preparation to final delivery — while presenting a clear, insight-driven story.

---

## 📊 Key Metrics
- Total Orders: 72K  
- Total Revenue: £7.80M  
- Average Delivery Time: 65.5 minutes  
- Average Preparation Time: 16.96 minutes  
- Late Orders: 62K  
- On-Time Delivery Rate: 5.03%

---

## 🔍 Key Insights
- **High Late Order Volume:** A significant proportion of orders are delayed, indicating operational inefficiencies  
- **Delivery Stage Bottleneck:** Delivery time contributes the most to overall delays  
- **Peak Hour Pressure:** Increased order volume during peak hours correlates with longer delivery times  
- **Logistics Challenge:** Driver allocation and routing appear to be major constraints
